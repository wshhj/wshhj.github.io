# Hero Blog V11

本版完成正式公开前的明显问题优化：

- 手机端新增汉堡菜单和抽屉导航，不再出现“手机上无法导航”的问题
- 首页摩托海报升级为红色赛博朋克纹路版本
- 个人页与联系页清理所有“待更新”占位内容
- 删除不可提交的静态联系表单，仅保留真实有效的 GitHub 入口
- 星空 Canvas 动画进一步优化性能：减少粒子、移除 O(n²) 连线计算、限制 DPR、36 FPS、页面后台自动暂停、支持减少动态效果
- 首页海报改为 WebP 并预加载，非首屏图片使用 lazy loading
- 按钮和交互控件 Hover 统一为白色反馈
- 所有版本更新说明只保留在 `updates.html`

部署：把压缩包解压后的全部文件覆盖上传到 `wshhj.github.io` 仓库根目录。
