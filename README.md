# Arthur Engineer Blog V3

正式个人工程师博客，适用于 GitHub Pages。

## V3 功能
- 工程师风格首页
- E-Bike / 电控 / 项目 / 成长分类
- 文章归档与分类筛选
- 站内搜索
- 工程项目作品集
- 视频页面
- 个人简历
- 关于页面
- 深色模式
- 手机端适配
- 404 页面
- GitHub Pages 直接部署

## 部署
把压缩包解压后的全部文件上传到：

`wshhj.github.io`

仓库根目录。

GitHub Pages 设置：

- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

## 修改重点
- 首页：index.html
- 文章：posts/
- 项目：projects/
- 样式：assets/style.css
- 搜索数据：assets/search.js
- 简历：resume.html
- 视频：videos.html
