# UART 通讯调试基础

UART 调试最容易犯的错误，是还没确认物理层就开始分析协议。

## 1. 先确认物理层

检查：

- TTL 电平是 3.3 V 还是 5 V。
- TX、RX、GND 是否正确。
- 单线通讯是否需要特殊收发结构。
- 是否共地。

## 2. 再确认串口参数

常见参数包括：

- Baud rate
- Data bits
- Stop bits
- Parity

只要其中一个错误，就可能出现乱码。

## 3. 抓真实报文

先不要急着模拟。从真实电池或真实控制器抓一组稳定报文，确认：

1. 帧头。
2. 长度。
3. 命令字。
4. 数据区。
5. 校验方式。

## 4. 最后做模拟

当报文结构确认后，再写自动应答工具。

```text
真实设备 -> 抓包 -> 解析 -> 验证 -> 模拟
```

这个顺序通常比直接猜协议更高效。
